01

개인사업자 등록 절차

홈택스 사업자등록 단계 + 업종코드 후보 + 현황 체크리스트입니다. 개인 명의 자산(도메인·계정 등)의 사업자 귀속 정리에 앞선 선행 단계입니다.

1-1. 등록 절차 (홈택스 온라인 기준)

단계내용소요상태
1홈택스 접속 → 공동인증서/간편인증 로그인즉시대기
2[신청/제출] → [사업자등록 신청(개인)]즉시대기
3인적사항·상호·사업장 주소 입력 (자택 가능)10분대기
4업종코드 선택 (1-2 표 참조)10분대기
5사업 개시일·과세유형 선택 (간이/일반)즉시대기
6임대차계약서 등 첨부 (자택 = 불요)—대기
7접수 → 처리 (통상 2~3 영업일, 즉시 발급 케이스 존재)2~3일대기
소요·비용 요약 온라인 신청 자체는 30분 이내, 발급까지 2~3 영업일. 등록면허세·수수료 0원(개인사업자 등록은 무료) — 자본금·설립등기가 필요한 법인과 본질적으로 다릅니다.

1-2. 업종코드 후보 (파트너·콘텐츠 운영 기준)

업태종목 (예시)업종코드 (예시)적용 사업
정보통신업포털·기타 인터넷 정보매개 서비스업642004파트너 사이트·데이터 포털
광고업온라인·모바일 광고 대행743002파트너 수수료(광고 매개)
서비스업데이터 처리·호스팅749609데이터 포털 운영
검증 보류 항목 업종코드는 후보입니다. 파트너 수수료의 정확한 업종 귀속(정보매개 vs 광고대행)은 세무사 1회 확인 후 확정합니다(추정 신고 금지). 통신판매업 신고 의무는 별건으로 섹션 3에서 다룹니다.

1-3. 현황 체크리스트 (추적)

  • 사업자등록 신청 완료
  • 사업자등록증 발급 수령
  • 업종코드 세무사 확정
  • 사업용 계좌 개설·홈택스 등록
  • 간이/일반 과세유형 확정
  • 개인 명의 자산(도메인·계정) → 사업자 귀속 정리 (양도 아님, 사업소득 귀속 정리)
02

파트너 가입 등록

제휴 파트너 업체별 가입 상태를 추적합니다. 가입 경로는 직접 가입 또는 네트워크 경유(Impact·Involve Asia·Stay22) 2종입니다.

정보 보호 트래킹 식별자·계정 이메일·승인 후 수익 수치는 비노출합니다. 가입 여부·승인 상태·정산 방식 등 구조만 게시하며, 트래킹 식별자 컬럼은 "내부 보관"으로 표기합니다.

2-2. 향후 확장 (후보)

  • 여행: 마이리얼트립 · 아고다 · 야놀자 · Trazy · GetYourGuide · 12go · EconomyBookings — 차별 각도 확정 후
  • 데이터 포털 관련: 증권·핀테크 제휴(미정·법무 선행). 데이터 포털 특성상 제휴 모델 적합성 별도 검토.

2-3. 가입 진행 순서

1순위 Stay22 가입 → 스크립트 설치

2순위 Travelpayouts → Airalo → Klook (네트워크 승인 1~2주 대기)

3순위 Booking · Trip.com · Skyscanner · KKday · NOL 개별 등록

전담 액션 파트너 계정 가입·관계 영업은 대표 전담입니다(계정·영업). 에이전트는 코드 인젝션·추적만 담당합니다.
03

운영 마이그레이션 (운영 전환·체계화)

가입 후 → 링크 주입 → rel="sponsored" → 정산 체계 → 운영 전환 단계를 추적합니다. "마이그레이션"은 파트너 운영의 전환·체계화를 뜻합니다.

3-1. 운영 전환 단계 체크리스트

단계항목상태근거
M1파트너 링크 코드 인젝션 (위젯·직접 링크)진행847 detail 페이지 인젝션 완료
M2도메인 화이트리스트 등록·승인 (파트너 대시보드)🔴 미완내부 운영 사고 기록
M3링크 변환 라이브 실측 3종 (콘솔 무에러·앵커 리라이트·CORS 통과)대기운영 게이트
M4rel="sponsored nofollow" 전 외부 파트너 링크 적용대기검색엔진 가이드·전상법
M5제휴 표시(disclosure) 문구 노출 ("제휴 링크 포함")대기신뢰·법무
M6도메인 컷오버 시 7곳 등록 도메인 동시 변경대기도메인 컷오버 Layer 2
M7정산 체계: 네트워크별 대시보드·세금계산서·사업소득 귀속대기세무사 연동

3-2. 핵심 리스크 — 죽은 수익 사일런트 데드

내부 운영 사고 기록 (제휴 링크 변환 차단으로 수익 추적 누락) Travelpayouts Drive 위젯이 CORS 차단으로 링크 변환이 전면 미작동 → 클릭 추적 0건 = 수수료 미발생. 코드는 박혔으나 외부 대시보드 도메인 승인이 누락된 상태였습니다. "콘솔 노이즈 무음화"로 처리했다면 죽은 수익이 영원히 은폐될 뻔했습니다.
운영 마이그레이션 게이트 (인정 기준) 인젝션 후 ① 콘솔 무에러 + ② 파트너 앵커 실제 리라이트(tp.media/r) + ③ CORS 통과 3종 라이브 실측을 통과해야 "동작"으로 인정합니다. "스크립트 박혔으니 동작" 가정은 금지합니다.

3-3. 정산·세무 연동

  • 네트워크별 수익은 사업자 사업소득으로 귀속됩니다(개인사업자 등록 선행 — 섹션 1).
  • 통신판매업 신고: 파트너(링크 송출·결제 미수령)는 신고 의무 회색지대입니다. 직전연도 거래 0회 = 현 면제 가능. 수익 발생 전 세무사/공정위 유권해석 1회 확정.
  • 신원표시: 파트너 플랫폼 심사 + 전상법 §10 → 실수신 이메일·연락처 확정이 필수입니다(NO-GO 항목).
