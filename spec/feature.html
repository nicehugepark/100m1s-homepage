100M1S 기능 요구사항 정의서 1차

본 정의서는 100M1S의 제품 라인업과 회사·플랫폼 기능 영역을 통합한 1차 산출물입니다. UI/UX 영역은 디자인 요구사항 정의서로 분리됩니다.

0. 메타

0.1 목적

  • 회사 인프라 + 5개 제품 라인업의 기능 영역을 단일 진실 출처로 1차 확정
  • 5 제품(P001~P004) × 4 도메인(회사·플랫폼 / 제품 / 데이터 / 운영·품질) 매트릭스 정합
  • 차기 분기 OKR + 제품별 PRD 작성 기반 확보

0.2 범위

  • 포함: 회사 인프라 + 4개 외부 제품 기능·플로우 + 데이터 파이프라인(개념) + 운영·품질 원칙
  • 제외: UI/UX·디자인 시스템 상세(짝 문서로 위임) / 모듈별 아키텍처 상세 / 내부 운영 도구 상세

0.3 갱신 정책

  • 본 정의서는 상위 통합 레이어이며 분기 1회 갱신
  • 신규 요구사항은 별도 등록 후 차기 정의서 사이클에 흡수

1. 회사·플랫폼

1.1 100m1s.com 홈페이지

  • 호스팅: GitHub Pages 기반 정적 사이트, 푸시 시 자동 배포
  • 태그라인 확정: "100 Million, 1 Step" / "1억, 한 걸음에"
  • 법무 페이지: 개인정보처리방침 / 이용약관 운영
  • /news: 회사 홈페이지 뉴스 보드 — 주식·부동산·정책 3 카테고리

1.2 에이전트 조직 (AI 협업 체계)

100M1S는 AI 에이전트 기반 협업 체계를 운영합니다. 도메인별 전문 에이전트가 병렬 협업하며, 결정·산출물은 모두 문서 체계로 기록됩니다.

  • 뉴스 분석 에이전트: 카페·RSS 다채널 수집 + LLM 기반 해석
  • 주식 투자 분석 에이전트: 시장·산업·모멘텀 분석 + 자율 매매 전략 학습
  • 오케스트레이션 에이전트: 사이클 운영 + 위임 + 작업 큐 관리
  • 품질·실패 분석 팀: 검증 + 회귀 방지 + 결함 분석
  • 문서 관리실: 산출물 코드 원자 할당 + 정합성 검증

1.3 문서·결정 거버넌스

  • 모든 결정·요구·결함은 표준 코드 체계로 기록 (DOC-YYYYMMDD-TYPE-NNN)
  • 작업 큐는 단일 진실 출처로 운영
  • 자동화 인프라: 세션 시작·종료 훅 + 자동 인덱스 동기화

1.4 운영 인프라

  • 워크트리·등급 운영: S(단일 작업) / M(팀 협업 1~3시간) / L(반나절+)
  • 자동화 훅: 응답 종료 시 체크포인트 + 파일 작성·수정 시 린트
  • 지속적 품질 개선 체계 운영

2. 5 제품별 기능

2.1 P002 PM320 (오후 3시 20분) — MVP 운영 중

컨셉

오후 3시 20분 동시호가 진입 직전, 당일 거래대금 상위 종목의 뉴스·테마·재료를 한 화면에 종합 — 단기 트레이더용 의사결정 보조 도구.

라이브 기능

  1. 거래대금 상위 종목 카드
    - 증권사 시세 API 다채널 수집(10분 주기 갱신)
    - 카드 구성: 종목명·6자리 티커·등락률·거래대금·테마칩·뉴스 요약
    - 미니 캔들 + 20영업일 일봉 차트(모바일 대응)
    - 신규 상장 종목 등락률 산출(시초가 대비)

  2. 뉴스 카드 (뉴스 분석)
    - 카페 + RSS 다채널 수집
    - LLM 직접 해석 기반 인사이트
    - 가비지 필터(VI/신고가/등락률 로봇 기사 제외)

  3. 테마칩 + 테마 트리
    - 표준 테마 사전(canonical) 기반 정합
    - 인과·내러티브 트리 + 자금 흐름 동기 분석
    - 7일 뷰 + 20일 스크롤

  4. 상태 뱃지
    - 시장경보·신용·단기과열 등 효과 배지 통합 명세
    - interval 기반 모델 + 14일 일괄 재빌드

  5. 차트·라벨 시스템
    - stale 라벨 렌더링
    - 7영업일 격리 + 17영업일 스크롤
    - 차트 레이아웃 정합 사이클 누적

상태

  • MVP 운영 중
  • 데이터 파이프라인 안정화 사이클 진행 중

2.2 P001 경매 분석 서비스 — 기획 진행 중

컨셉

부동산 경매 권리분석 + 등기부 자동 파싱 + 낙찰가 스코어링 — 본인 사용 검증 후 상용화 검토.

기획 항목

  • 권리분석 자동화 (등기부 파싱, 말소기준권리 식별)
  • 낙찰가 스코어링 모델 (지역·물건·낙찰가율)
  • 임장 체크리스트 + 모바일 리포트
  • B2C SaaS 전환 검토

상태

  • 기획 진행 중
  • MVP 범위·수익모델 미확정
  • 차기 사이클에 별도 PRD 작성 필요

2.3 P003 소마타 (So My Type) — 기획

컨셉

소개팅·이상형 매칭 + AI 이상형 생성 — 인간 본성 자극 서비스.

기획 항목

  • 이상형 프로필 입력 + AI 매칭
  • 연예인 닮은꼴 분석 + 이상형 생성
  • 데이팅 매칭 알고리즘

상태

  • 기획 단계
  • 외부 AI API 연동 준비 완료(호출 보류)

2.4 P004 글래스박스 (Glass Box) — 기획

컨셉

오픈채팅 관찰·관음 서비스 — "유리상자" 컨셉. 인간 본성 자극 서비스.

기획 항목

  • 채팅 관찰 모드 (참여 X, 구경 only)
  • 카테고리별 룸 분류
  • 익명·실명 모드 분기

상태

  • 기획 단계
  • MVP 범위 미확정

2.5 내부 운영 도구

대표 전용 내부 운영 도구가 별도 트랙으로 운영됩니다. 외부 노출 대상이 아닙니다.

3. 데이터 파이프라인 (개요)

3.1 시세·거래 데이터

  • 증권사 시세 API 다채널 수집
  • 거래대금 상위·일봉·신용잔고·분봉 등 항목별 분리 적재
  • 거래일 + 시간 기반 갱신 사이클

3.2 뉴스 수집 (카페·RSS)

  • 시간 단위 풀파이프라인 운영
  • 다양성 전제 파서 (단일 마커 파서 금지)
  • 형식 분류 + 추출 단계 분리

3.3 LLM 해석 레이어

  • 직접 호출 기반 해석 (중간 캐시 + 입력 해시 dedup 필수)
  • PROMPT 격리 + 응답 schema validation
  • 캐시 적중 이상치 알람

3.4 데이터베이스

  • 정규화 완료
  • 백필 사이클 + 모델 전환 + 상태 뱃지 정합

3.5 자동화 사이클 안전 원칙

  • 단일 진실 출처(SSOT) 파일 자동 수정 금지
  • 사이클 진행 중 큐 갱신 즉시 커밋 의무
  • destructive·publish 동작은 사전 결정 의무
  • 작업 큐 안전 보장 (60초 내 커밋 룰)

4. 운영·품질

4.1 워크트리·등급

등급 기준 운영
S 파일 1~2개, 30분 이내 단일 작업 + 워크트리
M 팀 협업 1~3시간 4팀 협업 + 워크트리 + 하네스
L 반나절+ 4팀 협업 + 하네스 + REQ 문서 + records commit

코드 수정 시 워크트리 사용 의무 (등급 무관).

4.2 하네스·QA 컨트랙트

  • 워크트리·작업판단·디자인선행·REQ존재·QA·스크린샷
  • M/L 등급에서 디자인-구현 정합 컨트랙트 의무

4.3 협업 매트릭스

  • 신규 문서 생성 시 문서 관리실 자동 협업
  • 자료 검색 시 뉴스 분석 에이전트 자동 협업
  • 두 트리거 동시 발생 시 동시 병렬 실행
  • 모든 멤버 임무 종료 시 자기 종료(self-shutdown) 의무

4.4 리더(lead) 메타 룰

오케스트레이션 리더가 따라야 할 21건 이상의 누적 결함 봉쇄 룰:
- 위임 직전 사전 검증
- 시스템 본래 망각 회피
- 좀비 사이클 회피
- 디자인 동시 갱신
- 직접 cross-check 금지(검증도 위임)
- destructive·publish 사전 결정
- 동일 이름 재생성 금지
- 자식 에이전트 자기 종료 룰
- 시간·간극 인지 룰
- 사전·사후 문서 룰
- 검증 1줄 의무 룰
- PROMPT 격리 + 캐시 schema validation 룰
- 백그라운드 launch 보고 + audit 룰

4.5 지속적 품질 개선 체계

회귀 방지·결함 분석·교훈 영구화를 위한 체계적 품질 개선 사이클이 운영되며, 모든 결함은 패턴 분류 후 메타 룰로 영구화됩니다.

5. 우선순위 매트릭스

P0 (즉시)

  1. 데이터 파이프라인 안정화 (백필·정합·핵심 누락 본질 fix)
  2. 신규 상장·신규 종목 자동 등록 hook
  3. SSOT 보호 자동화 영구 룰 운영
  4. 캐시 적중 audit 사이클 신설

P1 (1~2주)

  1. 파이프라인 단계 의존성 순서 근본 fix
  2. 종목 마스터 정정 사이클
  3. 도메인 룰 영구화 후속 점검
  4. 디자인 요구사항 정의서 본문 작성(짝 문서)

P2 (분기 내)

  1. P001 경매 분석 PRD 작성
  2. P003 소마타 MVP 범위 확정
  3. P004 글래스박스 MVP 범위 확정
  4. RSS 다중 source 확대 + fallback

P3 (백로그)

  • 알람 외부 채널 확장
  • 신규 채널 뉴스 수집 에이전트 신설
  • 다국어 토글 + 영문 정합

6. 도메인 룰 정확성

기획 검토 시 다음 도메인 룰 위반 금지:
- 한국 주식시장: ±30% 상하한가, VI(변동성 완화 장치), 거래시간 09:00~15:30, 동시호가 08:30~09:00 / 15:20~15:30
- 거래대금: 당일 단위 분리 적재
- 모의/실전: 릴리즈 전까지 모의 단계 운영
