100M1S 기능 요구사항 정의서 1차

본 정의서는 2026-04-05 ~ 2026-05-13 약 38일 동안 누적된 REQ 109건 + MIN 9 + DSN 35 + DEC 1 + FLR 78건을 흡수·통합한 1차 산출물입니다. 신규 정의서이며 기존 doc는 history로 보존됩니다. UI/UX 영역은 DOC-20260513-DSN-001로 분리합니다.

0. 메타

0.1 목적

  • 38일 누적 발화·결정·결함을 통합한 단일 진실 출처 1차 확정
  • 5 제품(P001~P005) × 4 도메인(회사·플랫폼 / 제품 / 파이프라인 / 운영·품질) 매트릭스 정합
  • 차기 사이클(분기 OKR + 분기 PRD) 작성 기반 확보

0.2 범위

  • 포함: 100M1S 회사 인프라 + 5 제품 기능·플로우·수익모델 + 데이터 파이프라인 + 운영·품질 룰
  • 제외: UI/UX·디자인 시스템 상세 (DSN-001) / FLR 78건 본문 (failures/INDEX.md 참조) / DSN-arch- 본문 (DOC-20260430-DSN-001-arch- 시리즈)

0.3 흡수 정책

  • REQ 109건 history 보존 (supersede 없음). 본 정의서는 상위 통합 layer
  • 본문 충돌 시 → 최신 doc + FLR 우선 (예: 큐 작업 운영은 DOC-20260511-MIN-001 §A 정책 우선)
  • 신규 REQ는 본 정의서 §부록 인덱스와 별도로 records/2026-MM/DOC--REQ-.md에 신규 등록 (정의서는 분기 1회 갱신)

0.4 관련 doc

  • 짝: DOC-20260513-DSN-001 (디자인 요구사항 정의서 1차)
  • 상위 결정: DOC-20260504-DEC-001 (토구사 미션 격상)
  • 최근 세션 인계: DOC-20260511-MIN-001 (5/8~5/11)
  • 리팩토링 기준: DOC-20260430-MIN-001
